# Product marks

The SVG marks in this folder come from
[Simple Icons](https://github.com/simple-icons/simple-icons/tree/1bb2f6e6ea50f920de8d2f3d273ae48564a5eaee).
The source revision is `1bb2f6e6ea50f920de8d2f3d273ae48564a5eaee`.
The files are unchanged. The source uses [CC0 1.0](LICENSE.md).
The exception is `dotnet.svg`. This project made it. It is a simple purple
square with the text ".NET". It is not the official .NET logo.

The marks identify these products or product families:

| File | Product or family |
|---|---|
| dotnet.svg | .NET (generic mark made for this project) |
| docker.svg | Docker |
| eclipseadoptium.svg | Eclipse Adoptium, the source of Temurin |
| git.svg | Git |
| github.svg | GitHub |
| githubactions.svg | GitHub Actions |
| githubcopilot.svg | GitHub Copilot |
| junit5.svg | JUnit 5 |
| mermaid.svg | Mermaid |
| opentelemetry.svg | OpenTelemetry |
| owasp.svg | OWASP, the project family for ZAP |
| python.svg | Python |
| trivy.svg | Trivy |

Product names and marks belong to their owners. Their use does not mean that
the owners endorse this project. The OWASP mark identifies the project family.
It is not a separate ZAP logo.

Some tools do not have a mark in this set. The explorer shows their names as
text labels. It does not invent logos.

All marks load from local files. The explorer does not send data to a logo
service. It shows where a tool is used and whether that stage exists or is
planned.
